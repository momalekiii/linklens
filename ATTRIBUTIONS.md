# External sources and terms

Original LinkLens code is audit-only. External data and services retain their own
licenses, attribution requirements, access rules and rate limits. Dataset contents
are fetched at runtime; no feed snapshots are bundled in this release.

| Source | Reference | Terms / role |
|---|---|---|
| MotmaenBash | https://github.com/miladnouri/motmaenbash-data | CC-BY-4.0; indicator data; attribution must be retained |
| Leakfa-Alert | https://github.com/Leakfarsi/Leakfa-Alert | MIT; regional breach feed |
| Kaveh | https://github.com/Nooshdaroo-Code/Kaveh | Upstream project terms apply; no blanket software license claim here |
| HIBP | https://haveibeenpwned.com/API/v3 | API/data terms apply; public breach catalog |
| Cloudflare | https://developers.cloudflare.com/1.1.1.1/encryption/dns-over-https/ | DNS-over-HTTPS service terms |
| RDAP | https://rdap.org/ | Bootstrap/registry availability and terms vary |
| Cert Spotter | https://sslmate.com/certspotter/api/ | Public CT API terms and limits |
| crt.sh | https://crt.sh/ | Public CT index; availability varies |
| URLScan | https://urlscan.io/docs/api/ | Search/API terms and limits |
| Telegram Serverless | https://core.telegram.org/bots/serverless | Runtime / SDK platform terms |

MotmaenBash license reference: https://creativecommons.org/licenses/by/4.0/
LinkLens indexes hashes and maps source data into reports; it does not claim
ownership of upstream records. This release does not replace upstream licenses.
Optional commercial API adapters are subject to each provider's own terms.
